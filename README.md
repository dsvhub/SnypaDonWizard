# SnypaDonWizard

A branded Kodi program add-on based on the OpenWizard project. SnypaDonWizard is being customized to provide build installation, add-on and repository management, backup and restore, maintenance, and configuration tools for supported Kodi devices.

## Project status

This package is an initial customization baseline. Build downloads, repository installation, add-on catalogs, and update feeds must be configured with URLs controlled by the SnypaDonWizard maintainer before those distribution features are enabled. Placeholder URLs are intentionally not treated as working sources.

## Target platforms

The add-on metadata declares support for Kodi platforms generally. Actual compatibility must be verified on the specific Kodi releases and devices being targeted, including Android/Android TV and Windows. The declared `xbmc.python` dependency currently targets Python 3-based Kodi releases.
