# SnypaDon Kodi Repository

This directory is reserved for the SnypaDon Kodi repository add-on.

The repository will publish only project-owned add-ons or add-ons that SnypaDonWizard is authorized to redistribute. The repository add-on metadata, versioned `addons.xml`, checksums, and ZIP packages will be added after the repository structure is implemented and tested.

This README is a directory marker, not an installable Kodi repository.
