# SnypaDonWizard

A modern, navy-and-blue branded Kodi program add-on for installing and maintaining a user-managed Kodi setup.

## Add-on identity

- **Display name:** SnypaDonWizard
- **Kodi add-on ID:** `plugin.program.snypadonwizard`
- **Repository owner:** `dsvhub`
- **Repository:** https://github.com/dsvhub/SnypaDonWizard

## Project goals

SnypaDonWizard is intended to provide:

- Installation and updates for a personally maintained Kodi build
- Installation of add-ons from sources the project owner is authorized to distribute
- A dedicated Snypa repository for project-owned add-ons
- Backup and restore of Kodi settings and user data
- Maintenance tools and configurable settings
- Consistent navy-and-blue branding

## Target platforms

The project is being developed for Kodi on Android/Android TV and Windows. Compatibility will be verified against the Kodi and Python versions supported by each target platform before releases are published.

## Development status

The GitHub repository is the project home. The add-on source package is being prepared and reviewed locally before the complete source tree and release artifacts are published here. Do not treat this repository as an installable Kodi repository until a tested repository structure and release are published.
